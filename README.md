# CTF Forensics Writeups

Digital Forensics CTF writeups and notes.
A collection of my forensics challenge writeups from various CTFs.

## About
This repo contains detailed, step-by-step solutions to forensics challenges (steganography, memory forensics, file carving, pcaps, etc.).  
Tools commonly used: Volatility, binwalk, foremost, Wireshark, exiftool, stegsolve, etc.
